# Citation guide

## Cite this derived dataset

Stop-GIS contributors. (2026). *Pittsburgh bus-stop bench-inventory starter
dataset* (Version 0.1.0) [Data set]. Stop-GIS.

If this package is published in a repository with a DOI or stable release URL,
append that identifier to the citation. Do not cite the starter dataset as a
verified bench census: all records remain unreviewed.

## Cite the source data

- Pittsburgh Regional Transit. (2026). *PRT Stops - Current (full system)*
  [Feature layer; ArcGIS item `a29f37608eb34c3895332ff99eea9b17`].
  Updated 2026-07-24; accessed 2026-09-04.
  https://www.arcgis.com/home/item.html?id=a29f37608eb34c3895332ff99eea9b17
- Pittsburgh Regional Transit. (2026). *PRT Stop Amenities - Current*
  [Feature layer; ArcGIS item `73d1faab8d3441babcd3463ef6987559`].
  Updated 2026-08-25; accessed 2026-09-04.
  https://www.arcgis.com/home/item.html?id=73d1faab8d3441babcd3463ef6987559
- OpenStreetMap contributors. (2026). *OpenStreetMap* [Database]. OpenStreetMap
  Foundation. Data queried through the Overpass API; accessed 2026-09-04.
  ODbL 1.0. https://www.openstreetmap.org/copyright

Suggested short attribution:

> Pittsburgh Regional Transit current stops and shelter data, used under the
> PRT Developer License Agreement; OpenStreetMap data © OpenStreetMap
> contributors, ODbL 1.0.

The short attribution does not replace the complete PRT notice required for a
derivative version. Preserve `DATA_LICENSE.md` with redistributed copies.

## What is not a data source

The Pittsburghers for Public Transit crowdsourced seating form is mentioned in
the README as context only. No records from that form are included, so it is
not listed as a source-data citation.
